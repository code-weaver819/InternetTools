Frequently asked questions

How accurate is the speed test?

Our speed test uses M-Lab's NDT7 protocol, the same technology used by researchers and ISPs worldwide. It provides highly accurate measurements of your download and upload speeds by testing directly between your browser and M-Lab servers.

Do I need to install anything?

No installation required! Our tools run entirely in your browser using modern web technologies. Just visit the page and start using them immediately.

Is my data stored or tracked?

No. We're privacy-focused. Speed tests run directly between your browser and M-Lab servers. We don't store your results or track your activity across sessions.

How often can I run a speed test?

M-Lab limits each device to 40 tests per 24-hour period. This prevents abuse and ensures fair access for everyone. The limit resets daily.
